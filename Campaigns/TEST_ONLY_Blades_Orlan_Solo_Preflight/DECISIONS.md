# 《暗夜刀锋》｜奥兰单人战役裁定与准备状态

> **战役状态：NOT STARTED**  
> **规则基准：《暗夜刀锋》中文版 V1.3**  
> **本文件状态：战役准备约定；正式游戏开始后，仍以实际场景与规则适用范围裁定。**

## 1. 战役形态

- 奥兰以**独立行动者**身份开始，不预先建立团伙，不预先创建团伙卡或团伙金库。
- 他按一个单人的团队理解和运行团队层级机制；这不代表开局已经拥有正式团伙组织、成员或资产。
- 团伙是否形成、何时形成、成员是谁，取决于游戏过程中实际建立的关系、人员、资源与共同业务。可以自然形成，也可以由玩家主动推动。
- 团伙正式成立后，再按 V1.3 建立团伙卡并处理层级、资源与金库。奥兰个人现金与团伙金库始终分开。

## 2. 团队暴露、罪熵与通缉

- **沿用 V1.3 原有团队层级的暴露/罪熵（Heat）与通缉机制。**
- 奥兰作为单人团队使用同一套机制，不另造“个人暴露”轨道，不另设单人阈值、换算公式或专属惩罚。
- 事件的声量、暴露范围和后果按实际行动规模、可见程度、影响与规则处理。单人行动通常不等同于大型团伙行动，但不设固定数值折扣。
- 不把同一事件重复计入，也不让未掌握情报的势力自动获知事件。团队暴露与某个 NPC/势力具体知道什么，是不同问题。

## 3. 死亡与偏执

这是奥兰的战役特殊设定，覆盖 V1.3 对角色创伤达到上限后的通常退场处理：

- 每次**实际死亡**会增加一次「偏执」创伤。
- 普通压力创伤、压力耗尽后的退出场景或其他非死亡退场，不算实际死亡，不增加偏执。
- 偏执达到创伤上限时，奥兰将**彻底死亡**，战役角色终结；不再套用“退休或入狱”的通常处理。
- 同一次死亡事件只结算一次偏执。
- 具体死亡判定边界、返回过程、时间间隔、位置、身体状态、伤害、物品、现场后果和压力变化，均暂不设定。真正遇到死亡事件时，再结合当时适用规则和场景讨论、裁定。
- 本准备文件不预先模拟或承诺任何具体复活细节，也不把未定义事项写成规则。

## 4. 角色与资源

- 奥兰·潘德瑞恩：低语者（Whisper），阿寇洛斯出身，贵族背景，特殊能力「风暴」。
- 开局个人现金：**2 硬币**。
- 奥兰在杜斯克沃尔有一处小型私人房产；它是个人住所，不自动成为团伙藏身处，不提供团伙据点加成。
- 家族不在杜斯克沃尔，关系冷淡、中立；家族持续提供基础生活资助，但金额与周期未量化，不自动增加可支配现金。
- 家族绝大多数人不知道奥兰死亡/复活的情况。具体死亡真相与隐瞒方式留白。
- 团伙成立后，团伙金库单独建立，不向奥兰个人重复发放资金。

## 5. NPC 与团队协作

### L1 / L2 / L3 是准备管理层级，不是系统规则术语

- **L1：** 普通雇员、临时帮手等，依据职责、质量与实际条件处理，不逐一模拟无关生活。
- **L2：** 关键关系人物，有稳定性格、关系和目标；平时轻量呈现，重要互动具体演绎。
- **L3：** 核心人物，具有独立人格、目标、能力、资源、知识边界和拒绝权；不是 GM 助手，也不是免费骰子来源。

目前没有正式设定的 L3 伙伴。具体原型、人物档案、能力效果、骰池贡献与团伙关系，留待未来确定，不预设、不自动加入。

### 团队合作

- 帮助、保护、创造条件等，仍按 V1.3 的适用规则处理。
- NPC 仅仅在场不会产生帮助骰。必须实际参与有意义的行动，并且愿意承担相应风险。
- L1 雇员依据质量与其实际执行的任务处理；L3 角色依据自身能力、行动与意愿处理。
- 不为了让单人行动显得容易而自动赠送协助，也不强制每项任务都需要多人配合。

## 6. 游戏循环与主持方式

- 基础循环：自由游玩 → 有明确目标与风险的刻痕（Job）→ Downtime → 自由游玩。
- 日常社交、拜访、休闲等不必全部转化为刻痕；没有新增选择、信息或风险的流程可摘要处理。
- 初期从局部、小型、个人事务开始，不预设大型黑帮冲突或城市阴谋，也不要求每次任务围绕幽灵展开。
- 世界自主运转，但只处理真正掌握相关情报、具有相关利益的势力；Downtime 计划与结算分开。
- NPC 依自身知识、目标、资源与条件行动；不得让 NPC 自动知道 GM 私有信息。
- 玩家可以失败、错过机会、绕开内容；不强行推进预设主线。
